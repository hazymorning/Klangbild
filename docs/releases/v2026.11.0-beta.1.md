### New
- **Lyrics in a group.** Some speakers play a little later when other speakers play along, so the lyrics run ahead of the voice. Klangbild can now hold the lyrics back while the speaker plays in a group. To use it, choose the same delay as in the speakers' app under Lyrics in a group in the settings.

### Better
- Set up on phone, a new line in the settings, shows the QR code for the setup page again, to change the speaker, other rooms, lights, sensors, buttons and values.
- Before a new version is installed, Update now shows what's new in it, point by point.
- Once the singing or the song is over, the last line of the lyrics no longer stays highlighted.

### Bug fixes
- With Music Assistant, the lyrics could fall a little behind the singing, more so at the start of a song. That should no longer happen.
- A title with several short words in a row could break into lines at an odd place. That should no longer happen.
